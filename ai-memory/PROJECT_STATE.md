# Current project state

## Purpose
Szkoleniowy dokument „Regulamin pracy hybrydowej BOBRTECH” (HR-REG-05) rozwijany promptami.
Case dla osób nietechnicznych: praca na dokumencie tekstowym, nie na aplikacji.

## Stack and commands
- Markdown w `dokumenty/`; brak aplikacji, zależności i serwera.
- Commity: hook AI Git Starter po turze agenta.

## Architecture
- `dokumenty/HR-REG-05_regulamin_pracy_hybrydowej.md` – treść regulaminu (v1.2).
- `README.md` – kontekst szkoleniowy.

## Implemented features
- v1.2: 3 dni zdalne/tydzień, wyjątek świąteczny, max 10 dni z zagranicy/rok,
  wtorek/czwartek jako dni biurowe, godziny bazowe 10:00–15:00, zwrot sprzętu w 5 dni roboczych,
  ryczałt 20 zł (max 160 zł) z proporcją na pierwszy/ostatni miesiąc.

## Known issues and limitations
- Wzór proporcji ryczałtu jest opisany słownie (przykład szkoleniowy) – bez kalkulatora.
- Brak załącznika z wnioskiem / checklistą zwrotu sprzętu.
