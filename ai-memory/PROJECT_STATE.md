# Current project state

## Purpose
Szkoleniowy dokument „Regulamin pracy hybrydowej BOBRTECH” (HR-REG-05) rozwijany promptami.
Case dla osób nietechnicznych: praca na dokumencie tekstowym, nie na aplikacji.

## Stack and commands
- Markdown w `dokumenty/`; brak aplikacji, zależności i serwera.
- Commity: hook AI Git Starter po turze agenta.

## Architecture
- `dokumenty/HR-REG-05_regulamin_pracy_hybrydowej.md` – treść regulaminu.
- `README.md` – kontekst szkoleniowy.

## Implemented features
- Wersja 1.1 (obowiązująca od 2026-11-12): 3 dni zdalne/tydzień, wyjątek na tydzień ze świętem,
  max 10 dni zdalnych z zagranicy/rok, ryczałt 20 zł (max 160 zł), VPN, zakres stanowisk biurowych.

## Known issues and limitations
- Brak jeszcze: godzin bazowych / dni biurowych obowiązkowych, procedur wyjątków poza świętem,
  zwrotu sprzętu, rozliczania ryczałtu przy niepełnym miesiącu.
